# Свадебное приглашение Асадбека и Севары

26 декабря 2026 года. Таджикская и узбекская версии на одной странице. Ссылка с параметром `?lang=uz` сразу открывает узбекскую версию.

## Локальный запуск

```sh
npm ci
npm start
```

Откройте http://localhost:3000. Для быстрого просмотра можно открыть `public/index.html` напрямую.

## Railway

Подключите GitHub-репозиторий к сервису Railway. В `railway.toml` указаны сборщик Railpack, команда запуска `npm start` и проверка доступности по пути `/`. Если сервис не поддерживает `railway.toml`, задайте эти параметры в настройках сервиса. Приложение использует переменную `PORT`, которую передаёт Railway. Для ссылки гостям создайте публичный домен в настройках сервиса.

### Ответы гостей и панель организатора

1. В **Variables** сервиса задайте `ADMIN_PASSWORD`. Для публичного сайта используйте пароль, который сложно угадать.
2. Подключите к сервису постоянный **Volume** с точкой монтирования `/data`. Railway передаст путь в `RAILWAY_VOLUME_MOUNT_PATH` автоматически. Оставьте один экземпляр сервиса.
3. После деплоя откройте `/admin` на домене приглашения и войдите по паролю. Здесь будут имена гостей, ответы о присутствии и пожелания.

Ответы сохраняются в `rsvps.json` на диске сервиса. Сайт принимает ответы после настройки пароля и Volume. При локальном запуске достаточно перед запуском задать `ADMIN_PASSWORD` в окружении. По умолчанию ответы хранятся в `data/rsvps.json`. Для отправки ответа открывайте приглашение через локальный сервер или сайт на Railway.
