# Свадебное приглашение Асадбека и Севары

26 декабря 2026 года. Таджикская и узбекская версии на одной странице. Ссылка с параметром `?lang=uz` сразу открывает узбекскую версию.

## Локальный запуск

```sh
npm ci
npm start
```

Откройте http://localhost:3000. Для быстрого просмотра можно открыть `public/index.html` напрямую.

## Railway

Подключите GitHub-репозиторий к сервису Railway. Railway запускает `npm start`, передаёт приложению переменную `PORT` и проверяет доступность страницы по пути `/`. Для ссылки гостям в настройках сервиса создайте публичный домен.

Адрес и ссылку на карту можно указать в объекте `CONFIG` в `public/index.html`. Гости могут подготовить ответ на приглашение, скопировать его и отправить организаторам.
